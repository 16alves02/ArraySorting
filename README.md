# 🔢 ArraySorting

A C console application created to explore and demonstrate classic **array sorting algorithms** through an interactive menu.

## 🧠 Algorithms

- Selection Sort
- Insertion Sort
- Bubble Sort
- Bogo Sort — included for educational demonstration

## ⚙️ What it demonstrates

- Arrays and loops
- Functions
- Menu-driven programs
- Sorting logic
- Input and output in C
- Checking whether an array is sorted

## 🚀 Run locally

Clone the repository, open the C source in your preferred C environment, compile it and run the resulting executable.

```bash
git clone https://github.com/16alves02/ArraySorting.git
cd ArraySorting
```
